# CRM/Omni vocabulary freeze -- the surface as measured at a12b9ebca.
# 705 files there, 708 here: the freeze's own three files name the
# vocabulary they police, and are frozen along with everything else.
#
# The `dotmac_crm` deployment ("Omni") was decommissioned 2026-08-29. Its
# surface inside Sub is replaced domain by domain, each slice deleting residue
# beside its replacement owner. This file holds the surface still in between.
#
# TWO-DIRECTIONAL. A path listed here that disappears fails the guard: lower
# the baseline in the SAME change that removes it, so every removal is a
# recorded decision rather than something noticed later. A path not listed
# here that appears fails it too: no new CRM or Omni dependency lands while
# the replacement programme is running.
#
# Membership is by identifier TOKEN, in the file's content or in its path,
# with camelCase split first. See tests/architecture/crm_vocabulary.py for why
# a word-boundary match would have missed nearly all of it.
#
# Michael's rule for every slice: a domain cannot claim cutover while its
# displaced CRM reader, writer, flag or transport remains.
#
# Most of this is not CRM-owned. Of the app files only ~21 are named for the
# CRM; the rest merely reference it. Read docs/designs/CRM_WEB_RETIREMENT.md
# before deleting anything on this list -- quote_mirror, referral_mirror and
# work_order_mirror are Sub-owned tables carrying CRM-era names, and dropping
# them would delete live data.
